# 社團器材借用系統｜多人同步版

這個版本以你提供的「社員版」與「管理員版」為基礎，保留原本介面與功能，將資料由瀏覽器 localStorage 改為伺服器端 JSON 資料庫，讓不同手機／電腦可以共用資料。

## 本機測試
1. 安裝 Node.js 18+
2. 在此資料夾執行 `npm install`（本專案無額外套件，但執行這一步可確認 npm 環境）
3. 執行 `npm start`
4. 社員：`http://localhost:3000/`
5. 管理員：`http://localhost:3000/admin`

預設管理員密碼：`admin123`。第一次上線後請立即在「設定 → 密碼」修改。

## 上線
可部署到任何支援 Node.js 的主機（例如 Render、Railway、Fly.io 等）。啟動指令為 `node server.js`。需要設定 `PORT` 時伺服器會自動讀取。

## 注意
`data/data.json`（或由 `DATA_DIR` 指定的資料目錄） 是伺服器資料庫，已加入 .gitignore，請務必做好備份。

此版本沒有把管理員密碼放在前端；管理員登入由伺服器驗證。社員查詢只會回傳符合姓名／學號／電話的紀錄；公開的器材時段資料不含姓名、電話、Gmail。
